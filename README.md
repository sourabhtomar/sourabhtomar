<h2>🔎 How I Approach Security Research</h2>

```text
┌───────────────────────────────────────────────────────────┐
│                    SECURITY RESEARCH                      │
├───────────────────────────────────────────────────────────┤
│                                                           │
│   Understand Application                                 │
│             ↓                                             │
│   Map Roles & Trust Boundaries                            │
│             ↓                                             │
│   Identify Security-Critical Workflows                   │
│             ↓                                             │
│   Manipulate Requests / Permissions                       │
│             ↓                                             │
│   Validate Impact Manually                                │
│             ↓                                             │
│   Build a Reproducible PoC                                │
│             ↓                                             │
│   Responsible Disclosure                                  │
│                                                           │
└───────────────────────────────────────────────────────────┘

I don't just scan for vulnerabilities — I try to understand the application and break the assumptions behind its security model.
