<h2>👨‍💻 About Me</h2>

<p>
I'm <strong>Sourabh Tomar</strong>, a Security Researcher and Bug Bounty Hunter focused on discovering and responsibly reporting vulnerabilities in modern web applications and APIs.
</p>

<p>
My primary research areas are <strong>Broken Access Control, IDOR, RBAC, privilege escalation, authentication, authorization, API security and business logic vulnerabilities.</strong>
</p>

<p>
I focus heavily on <strong>manual security research</strong> — understanding application behavior, mapping permissions and testing security assumptions rather than blindly relying on automated scanners.
</p>
