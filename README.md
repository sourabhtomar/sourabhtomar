<h2>👨‍💻 About Me</h2>

<p>
I'm <strong>Sourabh Tomar</strong>, a Security Researcher and Bug Bounty Hunter focused on discovering and responsibly reporting security vulnerabilities in modern web applications and APIs.
</p>

<p>
My research mainly revolves around understanding how applications behave internally — especially where <strong>authorization, permissions, trust boundaries and business logic</strong> can break down.
</p>

<p>
I strongly prefer <strong>manual security research</strong>, application understanding and controlled testing over blindly relying on automated scanners.
</p>

<h2>🔎 Research Methodology</h2>

<p align="center">
<strong>Understand</strong>
&nbsp; → &nbsp;
<strong>Map</strong>
&nbsp; → &nbsp;
<strong>Question</strong>
&nbsp; → &nbsp;
<strong>Manipulate</strong>
&nbsp; → &nbsp;
<strong>Validate</strong>
&nbsp; → &nbsp;
<strong>Document</strong>
</p>

<table>
<tr>
<td align="center">🧠<br><strong>Understand</strong><br>Application behavior</td>
<td align="center">🗺️<br><strong>Map</strong><br>Roles & trust boundaries</td>
<td align="center">🎯<br><strong>Question</strong><br>Security assumptions</td>
<td align="center">🧪<br><strong>Manipulate</strong><br>Requests & permissions</td>
<td align="center">✅<br><strong>Validate</strong><br>Real security impact</td>
<td align="center">📝<br><strong>Document</strong><br>Reproducible PoC</td>
</tr>
</table>

<blockquote>
<strong>I don't just scan for vulnerabilities.</strong><br>
I try to understand the application, identify its security assumptions and test where those assumptions fail.
</blockquote>
